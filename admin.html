Unlock

Paste your GitHub access key. It stays in this browser only and is sent to nobody except GitHub.

How to create the access key (one time, about 2 minutes)
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Name it Website manager and pick an expiry (for example 1 year).
  3. Under Repository access, choose Only select repositories → HAwebsite.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as is.
  5. Click Generate token, copy it and paste it above.

The key can only change this one repository. If a device is lost, delete the key on GitHub and make a new one.
